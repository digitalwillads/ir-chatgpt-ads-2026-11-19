ChatGPT ads tracking: what your web team adds

Three tags and one variable in Google Tag Manager, about 20 minutes. They work like your Google Ads and Meta tags: a base tag on every page, and an event when a form is sent or an order is placed. See the full ads plan.

1

Variable: OpenAI Pixel ID

A Lookup Table variable on {{Page Hostname}}, so one tag serves every brand in the container. We send the three pixel IDs as soon as the ChatGPT ads accounts exist.

Page HostnameOutput
www.airdimensions.comAir Dimensions pixel ID (we send it)

Any other hostname gets no output, so no OpenAI tag fires there.

2

Tag: OpenAI pixel, base

Tag typeCustom HTML
Fires onPage View, only where {{OpenAI Pixel ID}} matches RegEx .+ (a page of one of these sites), with the same cookie consent rule as your Meta pixel.
<script>
  (function (w, d, s, u) {
    if (w.oaiq) return;
    var q = function () { q.q.push(arguments); };
    q.q = [];
    w.oaiq = q;
    var js = d.createElement(s);
    js.async = true;
    js.src = u;
    var f = d.getElementsByTagName(s)[0];
    f.parentNode.insertBefore(js, f);
  })(window, document, "script", "https://bzrcdn.openai.com/sdk/oaiq.min.js");

  oaiq("init", { pixelId: "{{OpenAI Pixel ID}}" });
</script>

OpenAI's own snippet from its Measurement Pixel guide. It loads one small script from bzrcdn.openai.com. If the sites use a Content Security Policy, allow script-src https://bzrcdn.openai.com, connect-src https://bzr.openai.com and https://bzrcdn.openai.com, and img-src https://bzr.openai.com.

3

Tag: OpenAI, lead_created

Tag typeCustom HTML
Fires onThe same trigger as your Google Ads tag for GAds_form_sent_all: a form that was sent, not a button click.
<script>
  if (window.oaiq) {
    oaiq("measure", "lead_created", { type: "customer_action" });
  }
</script>

Tag sequencing: fire tag 2 before this tag. One form sent sends one lead.

4

Tag: OpenAI, order_created (shop container only)

Tag typeCustom HTML
Fires onThe same trigger as your Google Ads tag for GAds_purchase, in GTM-5DRHTRFG.
<script>
  if (window.oaiq) {
    oaiq("measure", "order_created", {
      type: "contents",
      amount: Math.round({{Order Total}} * 100),
      currency: "USD"
    }, { event_id: "{{Order ID}}" });
  }
</script>

{{Order Total}} and {{Order ID}} are the order value and transaction ID variables your GAds_purchase tag already uses. OpenAI takes the amount in cents, so $129.99 is sent as 12999.
