ChatGPT ads tracking for the web team

It's three tags and one variable in Google Tag Manager, and it works like the Google Ads and Meta tags you already have: a base tag on every page, then an event when a form is sent or an order goes through. It should take about 20 minutes. The full plan has the rest.

1. Variable: OpenAI Pixel ID

A Lookup Table on {{Page Hostname}}, so one set of tags covers every brand in the container. We'll send the pixel IDs as soon as the ChatGPT accounts exist. Any other hostname gets nothing, so the tags don't fire there.

2. Base tag

Custom HTML, firing on page views where {{OpenAI Pixel ID}} matches the RegEx .+, behind the same cookie consent as your Meta pixel.

<script>
  (function (w, d, s, u) {
    if (w.oaiq) return;
    var q = function () { q.q.push(arguments); };
    q.q = [];
    w.oaiq = q;
    var js = d.createElement(s);
    js.async = true;
    js.src = u;
    var f = d.getElementsByTagName(s)[0];
    f.parentNode.insertBefore(js, f);
  })(window, document, "script", "https://bzrcdn.openai.com/sdk/oaiq.min.js");

  oaiq("init", { pixelId: "{{OpenAI Pixel ID}}" });
</script>

This is OpenAI's own snippet. If the sites use a Content Security Policy, it needs script-src https://bzrcdn.openai.com, connect-src https://bzr.openai.com and https://bzrcdn.openai.com, and img-src https://bzr.openai.com.

3. Lead tag

Custom HTML on the same trigger as the Google Ads tag for GAds_form_sent_all, so it counts a sent form and not a button click. Set tag sequencing so the base tag fires first.

<script>
  if (window.oaiq) {
    oaiq("measure", "lead_created", { type: "customer_action" });
  }
</script>

4. Order tag (shop container only)

Custom HTML on the same trigger as the GAds_purchase tag in GTM-5DRHTRFG. {{Order Total}} and {{Order ID}} are whatever variables that tag already uses. OpenAI wants the amount in cents, so $129.99 goes in as 12999.

<script>
  if (window.oaiq) {
    oaiq("measure", "order_created", {
      type: "contents",
      amount: Math.round({{Order Total}} * 100),
      currency: "USD"
    }, { event_id: "{{Order ID}}" });
  }
</script>
